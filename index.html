⚙️ Configuratie — Apify API

1
Maak een gratis account aan op apify.com. Het gratis plan geeft je $5/maand aan gratis gebruik — meer dan genoeg voor dagelijkse syncs.
2
Ga naar Settings → Integrations in de Apify Console en kopieer je API Token.
3
De tracker gebruikt de Apify Actor dhrumil/propertyfinder-scraper. Vul hieronder je token in en klik op Synchroniseren. Data wordt automatisch bijgehouden en vergeleken met vorige syncs.
Token wordt lokaal opgeslagen in je browser
